# 豆格 Beadloom

一个完全在本机运行的拼豆图纸生成与编辑软件，同时提供 Windows 桌面版和浏览器版。上传 PNG、JPG 或 WebP 图片，选择图纸豆数和豆子规格后，即可得到带色号、底板分界及材料用量的可制作图纸。

## 已实现功能

- 拖拽或选择图片，内置试用示例
- 自定义图纸宽高，支持锁定比例及 29 / 58 / 87 颗快捷规格
- 5mm 大豆与 2.6mm 小豆的成品尺寸估算
- 按 29×29 常见方形底板估算拼板数量并绘制分界线
- 66 色工作室参考色板与 28 色入门参考色板
- CIEDE2000 感知色差匹配、最多用色限制与 Floyd–Steinberg 抖动
- 裁切、完整保留、拉伸三种适配方式
- 亮度、对比度、饱和度和透明阈值调节
- 圆珠效果与逐格色号视图，悬停查看坐标和色号
- 画笔、橡皮、区域填充与取色器，支持拖动连续编辑
- 撤销 / 重做（最多 50 步），支持 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Y`
- 自定义“我的库存”，生成时可只使用手头已有颜色
- 自动统计总豆数、实际用色和每色数量
- 导出高清 PNG 图纸、CSV 材料清单，或打印并另存为 PDF
- 版本化 `.beadloom.json` 项目导入导出，恢复时校验格子和色板数据
- 编辑结果自动保存到浏览器本机，刷新页面后可一键恢复
- PWA 安装与离线缓存、应用级错误恢复界面
- Windows 安装版与免安装便携版，支持系统“另存为”、系统打印和中文菜单
- Electron 单实例启动、沙箱隔离、严格内容安全策略和外部导航拦截
- 响应式桌面与手机布局；图片和图纸数据都不离开用户设备

## 技术选型

- **React 19 + TypeScript 7**：约束色板、单元格、参数和导出数据的一致性。
- **Vite 8**：开发和静态构建速度快，产物可直接部署到静态托管平台。
- **Canvas 2D**：在浏览器完成图片降采样、像素读取、预览和高清导出。
- **零业务后端**：当前需求无需账号与云端图库，本地处理隐私更好、部署成本更低。
- **Web App Manifest + Service Worker**：静态部署后可安装，并在首次加载后离线使用。
- **Electron 43 + electron-builder**：复用同一套 React 业务逻辑，输出 Windows 安装版和便携版。
- **Vitest**：保护颜色空间转换、CIEDE2000、编辑器填充、计数和项目恢复的正确性。

## 拼豆领域约定

- 标准大豆通常约为 5mm；Perler 官方给出的经典豆实际尺寸为约 5.07mm 高、4.77mm 宽。本项目用 5mm 估算成品尺寸。
- 小豆常见直径约 2.6mm，本项目用 2.6mm 估算成品尺寸。
- 图纸一格对应一颗豆。宽高决定细节、耗材、制作时间和成品物理大小。
- 常见可拼接方形底板按 29×29 颗估算；不同品牌底板可能存在差异。
- 屏幕色与塑料实物色会受显示器、批次、光线和熨烫程度影响，购买前应与实物色卡核对。

参考资料：[Perler 经典豆尺寸](https://perler.com/products/1-000-perler-beads-clear)、[Hama Midi / Mini 官方色板](https://www.hama.dk/media/104515/colour-palette-midiplusmini.pdf)、[Vite 官方指南](https://vite.dev/guide/)。

## 图像处理流程

1. 按目标豆数建立低分辨率 Canvas，保持比例或按用户指定方式裁切。
2. 应用亮度、对比度和饱和度调整，透明度低于阈值的像素变为空格。
3. 将像素从 sRGB 转为 D65 CIELAB，用 CIEDE2000 寻找最接近的参考豆色。
4. 按初次匹配的使用频率选出最多 N 种颜色，再映射到有限色集。
5. 可选 Floyd–Steinberg 误差扩散，用相邻颜色组合模拟色阶。
6. 统计每个色号数量，并绘制预览、底板边界、色号图纸和材料表。

## 使用项目文件

- 应用会在停止操作约 0.5 秒后自动保存当前图纸、生成参数和库存设置；原图本身不会写入自动保存。
- 点击“保存项目”可下载 `.beadloom.json` 文件。这个文件包含最终格子数据，即使没有原图，也能在另一台设备上打开并继续逐格编辑或导出。
- 点击“打开项目”可导入项目。应用会验证文件版本、图纸尺寸、色板和所有格子索引，并重新计算材料数量。
- 恢复项目后若要重新像素化或调整生成参数，请重新上传原图；已有图纸的编辑和导出不受影响。

## 离线安装

执行生产构建并通过 HTTPS 或本机地址访问后，可点击右上角“安装应用”。如果浏览器没有直接显示安装提示，也可从浏览器菜单选择“安装应用”或“添加到主屏幕”。首次成功加载生产版本后，核心界面会缓存到本机供离线使用。

## Windows 桌面版

本地执行 `pnpm desktop:build` 后，`release/` 中会生成两个 64 位 Windows 版本。安装包不纳入 Git 源码仓库；如果仓库发布了 Release，可从仓库的 Releases 页面下载：

- `Beadloom-1.0.0-x64-Setup.exe`：安装版，可选择安装目录，并创建桌面和开始菜单快捷方式。
- `Beadloom-1.0.0-x64-Portable.exe`：免安装版，双击后直接运行。

桌面版中的“保存项目”“清单”和“下载图纸”会调用 Windows 原生“另存为”窗口；“打印”会调用系统打印对话框。菜单栏可通过 `Alt` 显示，包含打开项目、保存项目、撤销、重做、界面缩放和全屏操作。

当前本地发布文件未使用商业代码签名证书。Windows SmartScreen 可能显示“未知发布者”；正式对外分发前建议购买代码签名证书并在构建环境配置签名。

## 本地运行

要求 Node.js 22+ 和 pnpm 11；当前项目使用 Node.js 24 验证。克隆项目后，在项目根目录执行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

生产构建与测试：

```bash
pnpm test
pnpm build
pnpm preview
```

桌面目录版、安装版和便携版：

```bash
pnpm desktop:pack
pnpm desktop:build
```

在无法直接访问 GitHub 构建资源的网络环境中，可临时设置 `ELECTRON_MIRROR` 与 `ELECTRON_BUILDER_BINARIES_MIRROR` 后再构建。项目锁文件会自动应用 `patches/` 中针对当前 electron-builder 下载缓存兼容问题的最小补丁。

## 目录结构

```text
src/
  components/              # 上传和拼豆画布组件
  data/palettes.ts         # 内置参考色板
  lib/color.ts             # sRGB / CIELAB / CIEDE2000
  lib/editor.ts            # 逐格编辑、计数、项目校验与序列化
  lib/export.ts            # PNG、CSV、打印导出
  lib/pattern.ts           # 像素化、限色、抖动、统计
  App.tsx                  # 工作台状态与界面
  styles.css               # 响应式视觉系统
  types.ts                 # 共享数据模型
electron/
  main.mjs                 # 桌面窗口、菜单、保存、打印与安全策略
  preload.cjs              # 沙箱渲染层的最小 IPC 桥
build/icon.png             # Windows 应用图标
electron-builder.yml       # 安装版与便携版打包配置
patches/                   # 可审计的第三方依赖兼容补丁
```

## 色板声明

“工作室 66 色”和“入门 28 色”是通用屏幕参考色板，编码以 `G / R / O / Y / B / L / T / C / P / N / M` 开头，仅用于生成与材料清单，不对应 Perler、Hama、MARD、COCO 或其他品牌的官方编号。
